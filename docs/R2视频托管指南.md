# Cloudflare R2 视频托管 + 站内播放 操作指南

> 当前采用：**方案 A · r2.dev 公开子域**（零配置、5 分钟可用）
> 以后升级：**方案 B · 绑定自定义子域**（见第 3 节，文件不用动，只换 URL 前缀）

---

## 0. 先判断：要不要用 R2

| 方案 | 优点 | 缺点 |
|---|---|---|
| **R2 直链 + `<video>`** | 画面干净无平台水印、可控、出流量免费 | 占 10GB 免费额度、要自己压片 |
| **外链平台嵌入**（新片场 / B站 / 腾讯视频） | 零存储成本、自带播放器和流量 | 有平台 UI、可能被平台下架 |

建议：**长片走外链嵌入，短片花/竖版片段放 R2 站内播放**。

R2 免费额度：存储 10GB、出流量（egress）0 元、A 类写入 100 万次/月、B 类读取 1000 万次/月。
单个对象上限 5TB，但网页播放建议压到 **50–200MB / 条**。

---

## 1. 创建存储桶

1. 登录 Cloudflare 控制台 → 左侧 **R2** → **Create bucket**
2. Bucket 名：`xjy-video`（小写、短、好记）
3. Location：`APAC`（或 Automatic）

---

## 2. 【当前采用】方案 A：r2.dev 公开子域

### 2.1 开启公开访问（4 步，全程在控制台点）

1. Cloudflare 控制台 → 左侧 **R2** → 点进 `xjy-video` 桶
2. 顶部 **Settings** 标签页
3. 找到 **Public access** 区块 → **r2.dev subdomain** → 点 **Allow Access**
4. 弹窗里输入 `allow` 确认

完成后该区块会显示一串地址，形如：

```
https://pub-1a2b3c4d5e6f7g8h9i0j.r2.dev
```

**把这串复制下来**，它就是你的视频根目录。（这串是 Cloudflare 自动生成的，改不了，每个桶一个。）

### 2.2 拼出视频地址

规则：公开地址 + `/` + 桶内路径

```
https://pub-1a2b3c4d5e6f7g8h9i0j.r2.dev/drama/lengshan.mp4
└──────────── r2.dev 根地址 ────────────┘└── 桶内路径 ──┘
```

按第 4 节的目录规范，全站会是这一批地址：

```
.../drama/lengshan.mp4            冷杉
.../drama/tudi-diedie.mp4         土地嗲嗲，天上要怎么走
.../drama/niaoniao-chuiyan.mp4    袅袅炊烟
.../drama/yupai-siyu.mp4          余牌思语
.../creative-shorts/biye.mp4      毕业视频《你想变成什么样的人》
.../creative-shorts/gongf1.mp4    莞工 F1
.../creative-shorts/mengli-yu.mp4 梦里我变成了一条鱼
.../aigc/mandela.mp4              曼德拉记录
.../aigc/anfa-qing-ruzuo.mp4      案发请入座
.../commercial/shandian.mp4       闪电 SPECIALIZED
.../commercial/bookoo.mp4         bookoo 咖啡
.../commercial/yuyun-nanyue.mp4   广东广播电视台「育孕南粤」
```

浏览器直接打开任一地址，能播放或下载就说明通了。

### 2.3 开启后立刻知道的三件事

⚠️ **整个桶对外公开可读** —— 任何人拿到文件路径都能访问。

- 只把允许公开的作品放进这个桶
- 甲方保密项目不要放这里（单独建一个**不开** Allow Access 的私有桶）
- 文件名建议加一段随机字符（见 2.4）

### 2.4 r2.dev 的限制（重要，决定你能不能长期用）

| 项目 | r2.dev（方案 A） | 自定义子域（方案 B） |
|---|---|---|
| 配置成本 | 点一下即可 | 要有自己的域名 + 改 NS |
| CDN 边缘缓存 | ❌ **不缓存，每次访问都回源** | ✅ 可缓存，回源次数大减 |
| 速率限制 | ⚠️ **有限流**，突发访问会被限速/报错 | ✅ 无此限制 |
| WAF / 防盗链 / 限速规则 | ❌ 用不了 | ✅ 都能配 |
| 出流量费用 | 免费 | 免费 |
| 读取次数（B 类操作） | **每次播放都算**，1000 万次/月 | 命中缓存后不计 |

**实际影响评估：**

面试作品集的场景是「少数人、短时间、点开看几条」，访问量很小，**r2.dev 完全够用**。
唯一的真实风险是：如果链接被发到大群里、或被爬虫反复抓，可能触发限流，表现为视频卡顿或加载失败。

**自我保护（做完这 3 条就可以放心用）：**

1. **压片**（第 5 节必做）：单条控制在 50–200MB，越小越省读取额度、越不容易卡
2. **文件名加随机后缀**：`drama/lengshan-7f3a.mp4`，避免被猜路径、被扫
3. **心里有底**：万一某天真的被刷，按第 3 节升级到自定义域即可，**文件一个都不用动**

### 2.5 以后升级到自定义域时，要改什么

只换 URL 前缀，其它一切不变：

```
https://pub-1a2b3c4d5e6f7g8h9i0j.r2.dev/drama/lengshan.mp4
                    ↓ 换成
https://video.你的域名.com/drama/lengshan.mp4
```

桶里的文件、目录结构、网页里 `<video>` 的写法全都沿用，
我这边批量替换 `src` 前缀就行，几分钟的事。所以**现在先跑起来，别纠结**。

## 3. 【以后升级】方案 B：绑定自定义子域

### 3.0 前置条件：域名必须先归 Cloudflare 管（最容易卡住的一步）

⚠️ **Cloudflare Pages 送的 `xxx.pages.dev` 域名不能用来绑 R2 自定义域**，必须有一个你自己的域名。
（买一个很便宜：`.top` / `.xyz` 之类一年十几到几十块。）

判断标准：Cloudflare 控制台左侧 **Websites** 里能看到这个域名，才说明它归 Cloudflare 管。

把域名交给 Cloudflare，两种方式（二选一）：

**A. 整个域名托管（推荐，最省事）**

1. Cloudflare 控制台 → **Websites** → **Add a domain** → 输入 `你的域名.com` → 选 **Free** 计划
2. Cloudflare 会给你两条 NS（形如 `xxx.ns.cloudflare.com` / `yyy.ns.cloudflare.com`）
3. 去你的域名注册商（阿里云 / 腾讯云 / Godaddy…）→ 域名管理 → **DNS 服务器 / Name Server** → 把 NS 改成这两条
4. 等 10 分钟～几小时生效（控制台里域名状态从 Pending 变成 Active）

**B. 只把 video 子域交给 Cloudflare（域名留在国内注册商也行）**

1. 同样先在 Cloudflare 里 Add a domain，拿到分配给你的两条 NS
2. 去注册商的 DNS 解析里，给 `video` 加两条 **NS 记录**，指向那两条 Cloudflare NS
3. 这样只有 `video.你的域名.com` 走 Cloudflare，`www` / `@` / 邮箱等记录完全不受影响

### 3.1 连接自定义域

1. R2 → 点进 `xjy-video` 桶 → **Settings**
2. 找到 **Public access → Custom Domains** → 点 **Connect Domain**
3. 填入 `video.你的域名.com` → **Continue**
4. 页面会预览即将写入的 DNS 记录（CNAME）→ 确认 **Connect Domain**
5. 状态会从 **Initializing** 变成 **Active**：通常几分钟，需要手动刷新页面看
6. 如果一直不变化：点自定义域右侧的 `...` → **Retry connection**
7. 想查看自动加的那条 DNS：点 `...` → **Manage DNS**

### 3.2 检查 DNS 记录

域名 → **DNS → Records**，应该自动多了一条：

| 类型 | 名称 | 目标 | 代理状态 |
|---|---|---|---|
| CNAME | `video` | `<一串字符>.r2.cloudflarestorage.com` | **已代理（橙色云）** |

⚠️ 橙色云必须开启，否则不走 Cloudflare 的缓存和安全防护。

### 3.3 验证

浏览器打开：`https://video.你的域名.com/drama/lengshan.mp4`
能播放或下载，就说明成功。

## 4. 上传文件 + 命名规范

**控制台**：进桶 → Upload，拖文件即可（适合少量小文件）。

**命令行（批量/大文件，推荐）**

```bash
# 方式一：wrangler
npm i -g wrangler
wrangler login
wrangler r2 object put xjy-video/drama/lengshan.mp4 --file ./lengshan.mp4
```

```bash
# 方式二：rclone（S3 兼容）
# endpoint: https://<account-id>.r2.cloudflarestorage.com
rclone copy ./videos r2:xjy-video/drama --progress
```

**命名规范（重要）**

- 目录：`creative-shorts/`、`aigc/`、`drama/`、`commercial/`
- 文件名：全小写英文 + 数字 + 连字符，例如 `drama/lengshan-7f3a.mp4`、`commercial/bookoo-2b9c.mp4`
- ❌ 不要中文、空格、括号（URL 会被转义，容易 404）

## 5. 上传前压缩（必做）

```bash
ffmpeg -i 原片.mov \
  -c:v libx264 -crf 23 -preset slow \
  -c:a aac -b:a 128k \
  -vf scale=1920:-2 \
  -movflags +faststart \
  out.mp4
```

- `-movflags +faststart`：边下边播，网页端必需
- 想再小：改 `-vf scale=1280:-2`，或换 HEVC
- 竖版视频不要 `scale=1920:-2` 横压，改成 `scale=-2:1920`

## 6. 配套设置（仅方案 B 可用，升级后再做）

> 以下三项都依赖 Cloudflare 的 CDN/WAF，**r2.dev 底下用不了**。
> 现在用方案 A 可以跳过整节；等你换到自定义域，回来照做即可。

### 6.1 缓存规则（不做 = 每次访问都回源，白耗 R2 读取额度）

Caching → **Cache Rules** → **Create rule**

- 名称：`r2-video-cache`
- **If**：`Hostname` `equals` `video.你的域名.com`
- **Then**：
  - Cache eligibility → **Eligible for cache**
  - Edge TTL → **1 month**
  - Browser TTL → **1 day**（可选）
- 点 **Deploy**

可选加分项：Caching → **Tiered Cache** → 开启 **Smart Tiered Cache**，进一步减少回源次数。

注意两点：

- 免费计划**单个文件可缓存上限 512MB**（我们的片子 50–200MB，安全）；超了就不缓存、每次都回源
- 默认并非所有文件类型都缓存，所以**显式建规则最稳**

### 6.2 防盗链（防止别人把你的视频嵌到别的网站）

推荐用 WAF 自定义规则（比 Hotlink Protection 更可控）：

WAF → **Custom rules** → Create rule

- 名称：`block-video-hotlink`
- 表达式：

```
http.host eq "video.你的域名.com"
and http.referer ne ""
and not http.referer contains "你的域名.com"
```

- 动作：**Block**（或 Managed Challenge）

效果：别的网站嵌入你的视频会被拦；用户在浏览器里直接打开链接仍然正常。

### 6.3 限速（防恶意刷流量）

WAF → **Rate limiting rules** → Create rule

- If：Hostname equals `video.你的域名.com`
- 阈值：单个 IP 10 分钟内请求 **> 200 次** → Block / Challenge

（免费计划通常有 1 条限速规则额度，够用。）

### 6.4 CORS

`<video>` 直接播放**不需要** CORS。
只有需要用 JS 读取视频像素、canvas 截帧时才要在桶上加 CORS 规则。

## 8. 常见坑

| 现象 | 原因 / 解决 |
|---|---|
| 播放一直转圈 | 没加 `-movflags +faststart`，或文件太大未压缩 |
| 403 / 404 | 桶未开 Allow Access，或路径含中文/空格 |
| r2.dev 突然加载失败/很慢 | 触发了 r2.dev 限流；先自查文件是否过大，长期方案是升级自定义域 |
| 手机上不播 | 用了 HEVC 但码率过高；备一份 H.264 |
| 流量/读取异常 | 链接被刷 → 升级自定义域 + 缓存规则 + 限速 |
| 自定义域一直 Initializing | 刷新页面；不行就 `...` → Retry connection |
| 绑域名时提示域名不可用 | 该域名不在 Cloudflare 账号里，先 Add a domain 再绑 |
| 视频能下但不缓存 | 缺 Cache Rules，或单文件超过 512MB |

## 9. 最短执行路径（照着做就行）

1. R2 → Create bucket `xjy-video`
2. 进桶 → Settings → **r2.dev subdomain → Allow Access** → 复制 `https://pub-xxxx.r2.dev`
3. ffmpeg 压片，单条 50–200MB，加 `-movflags +faststart`
4. 按 `分类/作品名-随机后缀.mp4` 命名，上传
5. 把「作品名 → 完整公开 URL」列表发给我 → 我接进四个分类页
6. （可选）以后买域名，绑 `video.你的域名.com`，我批量换前缀
