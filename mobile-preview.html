用自己的手机真机查看

  1. 手机和这台 Mac 连同一个 Wi-Fi
  2. 确认本地服务在跑：终端执行 node server.js
  3. 手机扫码，或浏览器输入 http://172.20.10.4:7878
  4. 用 Safari（iPhone）/ Chrome（安卓）打开，就是最真实的手机效果

⚠️ 二维码里的地址是 172.20.10.4，Wi-Fi 换了或重启路由器后这个 IP 会变。
变了的话告诉我，我重新生成一张；或者在 Mac 上执行 ipconfig getifaddr en0 查新 IP。
另：本地服务只对同一 Wi-Fi 内有效，外网访问需要等部署到 Cloudflare Pages。
